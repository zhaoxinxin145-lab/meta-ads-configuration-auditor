Privacy Policy

Last updated: October 15, 2026

1. About This Tool

Meta Ads Configuration Auditor is a personal-use tool for reviewing advertising configuration settings in Meta advertising accounts that the operator is authorized to access. It is not affiliated with or endorsed by Meta Platforms, Inc.

2. Information Processed

The tool may process advertising account identifiers, campaign, ad set and ad identifiers and names, delivery status, budget settings, attribution settings, targeting and placement settings, and available creative configuration fields through the Meta Marketing API.

3. How Information Is Used

This information is used only to review advertising configurations and generate audit reports for the operator's own use. The tool is designed to read configuration data and does not intentionally create, edit, pause or delete ads, or change advertising budgets.

4. Storage and Sharing

Audit reports are intended to be downloaded and stored by the operator. The operator should keep reports and access credentials secure. Access tokens must not be included in reports or published files. Any actual logging, temporary storage or third-party processing must be disclosed accurately before this policy is used.

Advertising data is not intentionally sold or shared with third parties by this tool.

5. Data Deletion

The operator can delete downloaded reports from the computer and other locations where copies were saved. To request deletion of any application-managed data, contact the operator using the email below. Please do not send passwords or access tokens.

6. Security

The operator should use access only for authorized advertising accounts, protect credentials, restrict access to reports, and revoke credentials that are no longer needed.

7. Changes

This policy will be updated if the tool's functionality or data handling practices change.
